INVENTARIO (ACCESIBLE A: reponedores, administradores):
-Boton buscar en inventario: Busca filtrando por nombre, si se ha introducido en el line edit, y por almacen, si se ha introducido en el almacen box.
-Almacen box: debe contener todos los almacenes disponibles como opciones al desplegarse
-Recargar: actualiza el inventario
-Añadir material: añade un tipo de material nuevo a la base de datos, el ID se autocompleta al ser autoincremental. El resto de datos necesarios para
la db se piden.
-Añadir lote: añade un lote de un material existente, pide en que almacen va a almacenarse (con un desplegable como almacenbox, mismo estilo css), el id del material
(con otro desplegable que muestre los materiales que existen en la base de datos) y el número de lote que se introduce manualmente.
-Modificar: permite modificar datos de los lotes para reducir su cantidad por ejemplo. Las cantidades no pueden ser negativas, si llega a 0 el lote se elimina.
-Mover: permite mover un lote de un almacen a otro, de nuevo esto se hace mediante boxes (desplegables) para evitar que se introduzcan datos no almacenados.
-Eliminar: permite eliminar lotes o materiales mediante el ID.


MAQUINARIA (ACCESIBLE A: técnicos, administradores):
-Boton buscar en maquinaria, y recargar mismo funcionamiento que para inventario pero aplicado a la maquinaria.
-Añadir máquina: Añade una nueva máquina. El ID se autocompleta igual que en el inventario. El resto de datos necesarios para la db se pide. El almacen donde 
se va a almacenar se introuce mediante un desplegable (como almacenbox).
-Modificar: permite modificar datos de una máquina como su nombre u otras cosas almacenadas en la base de datos. Esto se utiliza principalmente para actualizar las fechas
de revisión y los estados.
-Mover: sirve para mover una máquina via su id (introducido desde un desplegable que muestra todos los id almacenados) a un almacen nuevo (de nuevo mediante un desplegable).
-Eliminar: elimina una maquina de la base de datos.
